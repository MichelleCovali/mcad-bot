# MCAD — карта общей базы инцидентов

Карта и Telegram-бот используют один Python API и PostgreSQL. Исходные записи из Excel сохраняются полностью: нормализованные поля для поиска, исходные значения и ссылки для подробной карточки, история импорта. Реальные данные не вшиты в браузерный код.

## Разработка

Нужны Node.js 20.19+ и npm. Запустите Python API из корня проекта на порту 8090, затем в `frontend` выполните `npm install` и `npm run dev`. Vite направляет `/api` в `http://127.0.0.1:8090`. Настройки браузера можно сохранить в `.env.local` по примеру `.env.example`.

`npm run build` создаёт клиент в `dist/client`; Python сервер отдаёт его с того же адреса, что и API. `npm test` проверяет контракт данных и защищённых запросов. `npm run test:sites` проверяет сохранённую совместимость статического шаблона.

## Данные на карте

По умолчанию `VITE_API_BASE_URL=/api`. Карта загружает `GET /api/incidents`, затем обновляет данные каждые 45 секунд, когда вкладка видна, и при возврате во вкладку. Ошибка обновления помечает данные как устаревшие; предыдущие успешно загруженные записи остаются на экране.

Ответ списка: `{ "items": [...], "meta": { "total": 440, "mapped": 426, "unmapped": 14, "lastUpdated": "..." } }`. Эти числа — пример формы ответа; интерфейс отображает фактические данные сервера. Основные поля: `id`, `title`, `year`, `victimCountry`, `victimType`, `impactArea`, `incidentCountry`, `attackerCountry`, `locationName`, `latitude`, `longitude`, `locationPrecision`, `locationSource`, `description`, `sourceUrl`.

Координаты допускают только пару чисел в допустимом диапазоне либо пару `null`. Записи без достоверных координат остаются в списке с отметкой **Unmapped**, без выдуманной точки на карте. Страна инцидента и страна пострадавшей организации — разные поля. Точность и источник географии видны в карточке. Кластеры объединяют близкие и совпадающие точки; на максимальном масштабе открывается список инцидентов в одной точке.

Карточка открывается из маркера через **More information** или из **List view**. `GET /api/incidents/{id}` возвращает исходные поля `rawFields`, организации, акторов, географию, ссылки и строки источника. Формулы Excel отображаются как текст и не исполняются. Ссылки допускают только HTTP/HTTPS. Ссылка `/?incident=<id>` открывает конкретную карточку и перемещает карту к известной точке; такой адрес используется Telegram-ботом.

Поиск использует записи БД; фильтры **Victim country**, **Year**, **Victim type**, **Impact area**, **Incident country**, **Attacker country** работают по соответствующим полям. В режиме **All** небольшой локальный справочник дополнительно позволяет перейти к стране или городу без сетевого геокодирования.

## Проверка и публикация новых записей

Пункт **Report** или адрес `/admin` открывает защищённую панель. Введите серверный `ADMIN_API_TOKEN`; он хранится только в памяти открытой панели и не сохраняется в браузере. Закрытие панели завершает этот локальный сеанс.

Панель загружает `/api/admin/candidates`, позволяет прочитать первоисточник и проверить сведения, затем публикует через `/api/admin/candidates/{id}/approve`. Для ручного добавления используется `POST /api/incidents`. Все записи требуют серверной проверки токена; нет открытого публичного API записи. Указывайте фактическое местоположение инцидента, отдельно от страны пострадавшей организации. Если надёжных координат нет, оставьте оба поля пустыми.

Исторический импорт не создаёт массовую рассылку. Уведомления для новых опубликованных инцидентов выполняет серверная очередь, а не браузер. Доступность Telegram зависит от серверных настроек и подписок.

## Подложки карты

Без Google-ключа дорожный слой использует OpenStreetMap, спутниковый — Esri World Imagery. Атрибуция поставщика отображается на карте. Эти подложки отличаются от Google Maps в оригинале. `VITE_GOOGLE_MAPS_API_KEY` и необязательный `VITE_GOOGLE_MAPS_MAP_ID` подключают собственный Google Maps проект; успешный путь требует действующего ключа. При недоступности Google предусмотрен резервный слой.

Все `VITE_*` значения видны браузеру. Пароли БД, `TELEGRAM_BOT_TOKEN` и `ADMIN_API_TOKEN` задаются только на сервере. Происхождение оригинальных элементов оформления описано в [docs/asset-sources.md](docs/asset-sources.md).

В защищённой панели доступен импорт Excel: выберите `.xlsx` размером до 10 МБ и нажмите **Import workbook without notifications**. Файл передаётся двоичным телом в `POST /api/admin/import-workbook` с тем же токеном администратора; он не попадает в исходный код или публичные ресурсы. Отчёт показывает новые и существующие записи, точки на карте, записи без координат и карантин. Повторный импорт уже известной книги не создаёт дублей, исторические записи не вызывают рассылку.
