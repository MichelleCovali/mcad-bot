# MCAD — фронтенд карты

Интерфейс карты для совместной разработки. Реальные инциденты и демонстрационные маркеры не включены: без API карта остаётся пустой.

Для разработки нужны Node.js 20.19+ и npm. В папке `frontend` выполните `npm install`, скопируйте `.env.example` в `.env.local` и запустите `npm run dev`. Для сборки: `npm run build`. Проверки данных: `node --test tests/data.test.mjs`; проверка размещения: `npm run test:sites`.

## Карта и настройки

`VITE_GOOGLE_MAPS_API_KEY` — ваш собственный ключ Google Maps JavaScript API. Ограничьте его разрешёнными сайтами и нужным API в Google Cloud. `VITE_GOOGLE_MAPS_MAP_ID` — ID вашей карты, если нужен Google Maps. Не переносите ключи с исходного сайта. Все переменные с префиксом `VITE_` видны в браузере; пароли БД и серверные токены сюда не подходят.

Без ключа дорожный слой использует стандартные тайлы OpenStreetMap (`tile.openstreetmap.org`), спутниковый — Esri World Imagery. Атрибуция поставщиков отображается на карте. Оформление этих слоёв отличается от Google Maps; для точного воспроизведения исходного картографического слоя нужен собственный Google Maps API. При ошибке загрузки Google Maps, отклонённом ключе или ожидании более 15 секунд интерфейс переключается на резервную карту. Карта требует подключения к интернету. Поиск стран и городов использует небольшой локальный справочник Европы; сетевых запросов геокодирования при вводе нет.

## Подключение БД через API

Укажите `VITE_API_BASE_URL`, например `http://localhost:8000/api`. Фронтенд выполнит `GET http://localhost:8000/api/incidents` с заголовком `Accept: application/json`. Сервер должен разрешать CORS для адреса фронтенда, если работает на другом origin. Напрямую к БД браузер не подключается.

Ответ — массив записей или объект `{ "items": [] }`. Пустая БД возвращает пустой массив. Поля записи:

| Поле | Тип и правило |
| --- | --- |
| `id` | Непустая строка или неотрицательное целое число; уникальный ID |
| `title` | Непустая строка |
| `latitude` | Число от −90 до 90 |
| `longitude` | Число от −180 до 180 |
| `year` | Целое число от 1900 до текущего года; `null` или отсутствие, если неизвестно |
| `victimCountry` | Строка: страна пострадавшей организации |
| `victimType` | Строка: тип пострадавшей организации |
| `impactArea` | Строка: область воздействия |
| `incidentCountry` | Строка: страна инцидента |
| `attackerCountry` | Строка: страна атакующей стороны |

Неизвестные текстовые поля можно опустить или передать как `null`: интерфейс получает пустую строку. ID преобразуется в строку. Лишние поля ответа не передаются в интерфейс. Координаты и год передавайте числами, а не строками.

`src/data/incidents.js` содержит клиент `listIncidents({ signal })`, валидацию ответа и чистую функцию `filterIncidents(incidents, query, filterField)`. Доступны `all`, `victimCountry`, `year`, `victimType`, `impactArea`, `incidentCountry`, `attackerCountry`. Поиск не учитывает регистр. Ошибки HTTP, соединения, JSON и структуры данных показываются явно; фиктивной замены данных нет. `AbortSignal` отменяет запрос при закрытии или повторной загрузке.

В режиме `All` выбор страны или города перемещает карту; выбор найденной записи фильтрует по её заголовку. В режиме конкретного поля поиск и подсказки применяются к этому полю: например, выбор `Netherlands` при `Victim country` оставляет записи этой страны, а выбор `2024` при `Year` — записи за этот год. Страна в таком режиме одновременно служит точкой перехода на карте. Нажатие Enter без выбранной стрелками подсказки применяет введённый текст; в `All` найденное место открывается на карте.

Происхождение локальных ресурсов и границы копирования описаны в [docs/asset-sources.md](docs/asset-sources.md).

Этот каталог независим от Python-бота в корне репозитория. Бот пока не предоставляет веб-API и не сохраняет географическую модель инцидентов.
